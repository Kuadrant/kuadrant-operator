# Security Policy

## Supported Versions

Kuadrant currently supports the following versions with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Kuadrant seriously. If you discover a security vulnerability, we appreciate your help in disclosing it to us in a responsible manner.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to the maintainers directly. You can do this by emailing the Kuadrant maintainers at: `kuadrant@googlegroups.com`

When reporting a vulnerability, please include the following information:
* A description of the vulnerability and its impact.
* Steps to reproduce the vulnerability.
* Any relevant proof-of-concept code or screenshots.
* Which version(s) of Kuadrant are affected.

### What to expect
* We will acknowledge receipt of your vulnerability report as soon as possible.
* We will send you regular updates about our progress in resolving the issue.
* After the issue is resolved and a fix is released, we will publicly acknowledge your responsible disclosure (unless you request to remain anonymous).
